# madrasa-licenses — লাইসেন্স মেশিন

মাদরাসা ম্যানেজার সফটওয়্যারের অনলাইন লাইসেন্স ব্যবস্থাপনা।

## কী কী আছে

| পাথ | কাজ |
|---|---|
| `admin/` | **লাইসেন্স মেশিন** — ওয়েব অ্যাডমিন প্যানেল (লগইন, মেইন/সাব অ্যাডমিন, লাইসেন্স তৈরি, তালিকা, বাতিল) |
| `revocations.json` | স্বাক্ষরিত বাতিল তালিকা — ডেস্কটপ অ্যাপ এটা পড়ে অনলাইনে এলে বাতিল লাইসেন্স বন্ধ করে |
| `data/users.json` | ব্যবহারকারী (মেশিন থেকে তৈরি হয়) |
| `data/licenses.json` | সব লাইসেন্সের রেকর্ড (মেশিন থেকে তৈরি হয়) |
| `admin/SPEC.md` | বাতিল-তালিকার ফরম্যাট ও স্বাক্ষর পদ্ধতির নথি |

## মেশিন চালু

লিংক: `https://<username>.github.io/madrasa-licenses/admin/`

প্রথমবার: GitHub টোকেন (classic, `repo` scope) + মেইন অ্যাডমিন অ্যাকাউন্ট + Owner-Key.json-এর লেখা দিলেই মেশিন প্রস্তুত।

## নিরাপত্তা নোট
- এটা বিশ্বস্ত অ্যাডমিনদের জন্য প্র্যাকটিক্যাল প্যানেল; আসল নিয়ন্ত্রণ GitHub টোকেনে।
- `Owner-Key.json`-এর গোপন চাবি কখনো এই রিপোতে রাখবেন না — শুধু ব্রাউজারে পেস্ট করবেন।
