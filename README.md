# Madrasa Manager — License Revocation List

এই রিপোজিটরি Madrasa Manager সফটওয়্যারের **বাতিল লাইসেন্স তালিকা** হোস্ট করে।

## কীভাবে কাজ করে

১. মালিক License-Generator-এ কোনো লাইসেন্স **বাতিল** করলে, জেনারেটর `revocations.json` ফাইলে সেই license ID যোগ করে গোপন চাবি দিয়ে **স্বাক্ষর** করে।
২. স্বাক্ষর করা ফাইল এই রিপোজিটরিতে আপলোড করা হয় (GitHub Pages-এর মাধ্যমে প্রকাশিত হয়)।
৩. গ্রাহকের Madrasa Manager সফটওয়্যার ইন্টারনেট পেলেই এই ফাইলটি ডাউনলোড করে স্বাক্ষর যাচাই করে — নিজের license ID তালিকায় পেলে লাইসেন্স স্বয়ংক্রিয়ভাবে বাতিল হয়ে যায়।

## গোপনীয়তা

- ফাইলে শুধু বাতিল license ID (এলোমেলো অক্ষর) থাকে — কোনো নাম, ঠিকানা বা ব্যক্তিগত তথ্য থাকে না।
- তাই Public রিপোজিটরি নিরাপদ। স্বাক্ষর ছাড়া কেউ ভুয়া তালিকা বানাতে পারবে না।

## সতর্কতা

`revocations.json` হাতে এডিট করবেন না — স্বাক্ষর নষ্ট হয়ে যাবে। সবসময় License-Generator দিয়ে প্রকাশ করুন।
